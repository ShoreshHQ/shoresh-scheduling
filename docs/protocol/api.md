# API protocol: Data in and out

How data comes into Shoresh from outside systems and how schedules go out to them, by Flow
action, a web address with a key, or a CSV file. API uses CORE's terms (layer 1: Group,
Division, Activity, Lock, Hand edit, Conflict, Published) and explanation (layer 6); an incoming
batch is an import, so it obeys INGEST (docs/import/*.md); what goes out is what PUB published
or finalized. It never redefines a CORE term and never changes an INGEST or PUB rule. The
numbering, statuses and tests are in [README.md](README.md). Sources: wiki
`projects/shoresh-api.md` (with "Greg's answers (2026-10-29)"), wiki decision 0009, ADR 0024.
Greg's latest dated word wins.
