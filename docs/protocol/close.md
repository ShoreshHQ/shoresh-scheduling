# CLOSE protocol: closures, groups away and rainy days

What does not run in a given week, and what changes on a wet day. A **closure** (CORE-1.24) is an
activity, location, fixed or recurring activity that does not run in a week; a group **away**
(CORE-1.25) is not at camp that week. Both are set on the week, one mark per week (Greg,
2026-10-27: a group away is set on the week like other closures; `WeekException__c`). A **rainy
day** switches one day's outdoor activities to their rain plans (ADR 0019).

CLOSE feeds GEN's layer 4. It uses CORE layer 1 (1.24, 1.25), layer 4 (CORE-4.3, CORE-4.6),
layer 5 (CORE-5.8) and layer 6 (CORE-6.1, 6.2, 6.3). It never redefines a CORE term. IDs, tests
and the index are as in [README.md](README.md).

## Already stated by GEN

- GEN-1.2: an activity closed this week, or at a place closed this week, is left out of a build.
- GEN-1.3: every activity closed stops the build, saying so.
- GEN-2.6: a cell where the group isn't at camp is never filled.
- GEN-9.9: a hand edit is never refused for a closure, a group away or not at camp; it is saved
  with a reminder.
- GEN-10.2, 10.7: a Rebuild empties a placement a closure no longer allows, and says each one.
