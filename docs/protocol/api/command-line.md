# API protocol: Command line and code mode

Part of the API protocol, [Data in and out](../api.md), which holds its terms, sources and
numbering. How a command is typed, what it prints and how it ends; and MCP's actions as functions in
a script.

A statement whose Test cell starts "gap" has no test yet.

## Command line

The command line is MCP's actions typed in a terminal (API-1.10): `node shoresh.js <action> ...`
from the connector folder (or `node connect/cli.js` in this repo). It adds no capability and no
rule of the API's; these say how a command is typed, what it prints and how it ends. Checked end to
end against the test org by hand with `scripts/e2e-connect.js` (not in CI).

## Code mode

Code mode is MCP's actions as functions in a script (API-1.18): `const shoresh =
require("./code")`, then `await shoresh.<action>({ ...fields }, { org })`. An AI in a chat (Claude
desktop, Hermes) reaches it through one MCP tool, `run_shoresh_script`: it writes one short script
that makes many calls, instead of calling one tool at a time (Greg, 2026-10-30). It adds no
capability and no rule of the API's.
