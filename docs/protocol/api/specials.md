# API protocol: Special days and special events

Part of the API protocol, [Data in and out](../api.md), which holds its terms, sources and
numbering. Reading and placing a season's special days and special events, and their own schedules,
through an AI tool or the command line.

| API-1.74  | An AI tool or the command line MAY put a special day on a day of a week (`put_special_day_on_day`, `/v1/put_special_day_on_day`) and take one off (`take_special_day_off_day`, `/v1/take_special_day_off_day`). Each MUST be the screen's own action (SpecialPlacingController.putOnDay / takeOffDay: the week's own cells kept, the special day kept saved) and MUST carry what that week day has as read (`seen`: the special day's exact name, capitals counting, or "none"), compared while the week is locked: a day changed since MUST be refused (409) with nothing changed, an action without seen refused. Another special day on the day MUST NOT be replaced unless the request says `replace: true`; without it the answer is the screen's own question with nothing changed, and the tool MUST tell the AI to ask the person first. The answer MUST say how to undo it (the other action; a replaced special day stays saved).
