# API protocol: Capabilities and the connector

Part of the API protocol, [Data in and out](../api.md), which holds its terms, sources and
numbering. What a capability is called and how an AI tool or the command line reaches it: one name
and web address each, the person's own sign-in, connecting an AI app, the season used when none is
named, names that aren't there, refusals in plain words, and the connector being the camp's own
copy.
