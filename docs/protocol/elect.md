# ELECT protocol: Electives

Electives split campers from chosen groups across an elective set's offerings, in the set's
times. ELECT sits on GEN's week: its sets are kept cells there (CORE-5.1), and seating campers
never moves a group's placement. It uses CORE's terms (layer 1), reads choices sheets by CORE
layer 2, keeps CORE's limits (layer 4) with seats as the elective's own limit, follows CORE's
placement order (layer 5) and explains by CORE layer 6. It never redefines a CORE term. The
numbering, statuses and tests are in [README.md](README.md). Sources: wiki
`projects/shoresh-protocol.md` (D, E 48), ADRs 0016, 0017, 0018. Greg's latest dated word wins.

A statement whose Test cell starts "gap" has no test yet; "contradicted" means today's code does
otherwise and Greg has not yet ruled on which changes.
