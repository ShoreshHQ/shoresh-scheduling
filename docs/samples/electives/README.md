# Sample choices sheet for the electives walkthrough

`chugim-choices.csv` is invented: six made-up campers in _Bunk 1_ and _Bunk 2_ (the bunks the
walkthrough sets up in section 6), each choosing Archery, Drama and Pottery in order, with one
parent comment. It is laid out the way a camp's own form often hands choices over (a camper
number, the child's name, the bunk, ranked choices, a comments column). Walkthrough:
`docs/try-camp-setup.md`, section 31. The reader's own test corpus is `docs/samples/choices`.
