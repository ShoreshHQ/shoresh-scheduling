# Sample lists for Import a list

Everything here is invented, for the made-up camp _Maple Grove Day Camp_ of
`docs/samples/import` (import that first: walkthrough section 14). One list per screen, in the
layout Shoresh writes, plus one column Shoresh doesn't know (_Colour_).

| File                           | Screen               | Planted on purpose                                                                                                                                                         |
| ------------------------------ | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `maple-grove-locations.csv`    | Locations            | three location types the season doesn't have (added with the list); _Gym_ fits "two" groups (can't be read)                                                                |
| `maple-grove-activities.csv`   | Activities           | _Musik_ (typo of Music); _Music room_ and _Gaga pit_ (new locations); _Movies_ (a rain plan that isn't set up); _Middlers_ (not a unit or bunk); _Hiking_ outdoors "maybe" |
| `maple-grove-program-days.csv` | Program days         | _Teens_ is new; _Weekend_ runs on Saturday (can't be read)                                                                                                                 |
| `maple-grove-units.csv`        | Units                | _Middlers_ is new; _Explorers_ isn't a program yet (asked: which days?)                                                                                                    |
| `maple-grove-bunks.csv`        | Bunks                | _Bunk 3_ in another unit (a move); _Middlers_ added with _Bunk 7_; _Bunk 8_ "sometimes" (can't be read)                                                                    |
| `maple-grove-time-blocks.csv`  | Time blocks          | _Period 2_ starts 5 minutes later; _Late pickup_ at 6:00 (morning or evening?); _Swim time_ ends before it starts                                                          |
| `maple-grove-fixed.csv`        | Fixed activities     | _Dining hall_ is new; _Snack break_ isn't a time block yet (asked: when?)                                                                                                  |
| `maple-grove-recurring.csv`    | Recurring activities | _Morning meeting_ on Wednesday too; _Rest hour_ for Juniors and _Middlers_ (asked what Middlers is, unless the units list added it); _Campfire_ on Saturday                |

Walkthrough: `docs/try-camp-setup.md`, sections 15 and 16.
