# Sample lists for Import a list

Everything here is invented, for the made-up camp _Maple Grove Day Camp_ of
`docs/samples/import` (import that first: walkthrough section 14). One list per screen, in the
layout Shoresh writes, plus one column Shoresh doesn't know (_Colour_).

| File                         | Screen     | Planted on purpose                                                                                                                                                         |
| ---------------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `maple-grove-locations.csv`  | Locations  | three location types the season doesn't have (added with the list); _Gym_ fits "two" groups (can't be read)                                                                |
| `maple-grove-activities.csv` | Activities | _Musik_ (typo of Music); _Music room_ and _Gaga pit_ (new locations); _Movies_ (a rain plan that isn't set up); _Middlers_ (not a unit or bunk); _Hiking_ outdoors "maybe" |

Walkthrough: `docs/try-camp-setup.md`, section 15.
